# Run-IQ brand

The mark is a loop of three steps: input, rules and decision. The blue node is the decision.

| File | Use |
|---|---|
| `mark.svg` | The mark in `currentColor`, for code (the decision node stays blue). |
| `mark-on-dark.svg`, `mark-on-light.svg` | The mark with fixed colours. |
| `avatar-dark.svg`, `logo-dark.png`, `logo-light.png` | Square logo, 1000 px. |
| `favicon.svg` | Browser icon. |
| `banner.png` (2400 × 600), `banner-linkedin.png` (3168 × 792) | Banners (GitHub, LinkedIn personal profile). |
| `linkedin/` | LinkedIn company page: `logo.png`, `cover.png` (1128 × 191 ratio) and the page texts in `page.md`. |
| `social-preview.png` (1280 × 640) | Generic social preview. |
| `social/<repo>.png` (1280 × 640) | Social preview of each public repository (`dot-github.png` for `.github`). |
| `loader.html` | Loading animation: the loop breathes and turns a third, then the decision slides back to the top. |

## Colours

| Name | Hex |
|---|---|
| Ink | `#0B0B0B` |
| Paper | `#F2F1EC` |
| Decision blue | `#2F5BEA` |
| Grey | `#66666B` |

## Type

Inter, semibold for the wordmark (tight tracking), regular for text.
